Project 5: Memprediksi Starter NBA 2023: Perpaduan Regresi Linier dan Logistik

Di proyek ini, saya mencoba memprediksi siapa saja pemain yang layak menjadi starter di NBA menggunakan dataset NBA 2023 dari Kaggle. Saya menggunakan dua pendekatan: Regresi Linier Sederhana dan Regresi Logistik. Dengan Regresi Linier Sederhana, saya melihat hubungan antara fitur-fitur tertentu dengan jumlah pertandingan sebagai starter (GS). Nilai GS ini kemudian saya jadikan patokan untuk menentukan status starter. Saya juga menggunakan matriks korelasi untuk memilih fitur yang paling relevan, lalu mengevaluasi model dengan MAE, MSE, R², dan RMSE. Setelah itu, saya lanjutkan ke Regresi Logistik untuk mengklasifikasikan pemain sebagai starter atau bukan, berdasarkan hasil dari model sebelumnya. Di tahap ini, saya menggunakan confusion matrix, akurasi, presisi, dan recall untuk melihat seberapa baik model bekerja. Proyek ini saya buat sebagai bagian dari proses belajar dan eksplorasi saya di dunia data.

  • Menampilkan hasil dari operasi perbandingan: lebih besar, lebih kecil, sama dengan, tidak sama dengan, dan sebagainya.

  • Mengakses elemen tertentu dari list untuk menunjukkan pemahaman tentang struktur data.
